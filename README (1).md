# AI & Machine Learning Topics — Laboratory Projects

This repository contains practical laboratory exercises for **Introduction to Artificial Intelligence and Machine Learning**. The labs cover the basics of Python and data analysis, followed by machine learning algorithms and introductory deep learning techniques.

## Lab Topics

| Lab | Topic | Description |
| --- | --- | --- |
| 01 | Python and Jupyter Setup | Introduction to Python, Jupyter notebooks, and basic data handling. |
| 02 | Web Scraping and Exploratory Data Analysis (EDA) | Collecting, cleaning, exploring, and visualizing data. |
| 03 | Text and Image Feature Extraction | Converting text and image information into numerical features for analysis. |
| 04 | Linear Regression | Using supervised learning to predict numerical values, such as salaries and house prices. |
| 05 | Titanic Classification | Predicting passenger survival using classification techniques. |
| 06 | Model Training and Deployment | Training, evaluating, saving, and using a machine learning model. |
| 07 | Convolutional Neural Network (CNN) Layers | Exploring convolution, activation functions, and pooling for image data. |
| 08 | Handwritten Digit Recognition | Recognizing handwritten digits using image classification techniques. |

## Main Concepts

- Python programming and Jupyter notebooks
- Data collection, preprocessing, and visualization
- Feature extraction and selection
- Supervised learning: regression and classification
- Model training and evaluation
- Model saving and reuse
- Introduction to neural networks and image recognition

## Technologies Used

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Common libraries:** NumPy, Pandas, Matplotlib, and scikit-learn
- **Other dependencies:** Refer to the notebooks or requirements files for lab-specific packages.

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/ahm3draz4/AI_Machine_Learning_Topics_Labs.git
   ```

2. Open the project folder and launch Jupyter Notebook, or upload an individual notebook and its dataset to Google Colab.
3. Open the lab folder you want to explore.
4. Install any required libraries, then run the notebook cells in order.
5. Keep the datasets alongside the corresponding notebooks and adjust file paths if necessary.

> **Note:** Some notebooks may need additional dependencies or an internet connection. All notebooks have not been independently verified to run end-to-end in a fresh environment.

## Repository Organization

Each lab is organized in a separate folder named after its topic, with the lab number at the end. Depending on the lab, folders may contain Jupyter notebooks, Python scripts, datasets, and supporting files.

## Project Objective

The purpose of these labs is to gain practical experience with the main steps of an AI/ML project: preparing data, extracting features, training models, evaluating results, and applying trained models to real examples.
