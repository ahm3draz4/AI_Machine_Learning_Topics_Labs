# Introduction to Artificial Intelligence — Simple Lab Portfolio

A compact, notebook-first collection of eight AI labs for learning and viva preparation. No web app or deployment components are included.

## Lab overview

| Lab | Topic | What it demonstrates |
|---|---|---|
| 01 | Jupyter and Python setup | Jupyter runs Python code cell by cell. |
| 02 | Web scraping and EDA | Collect text data, clean it, and explore it using plots. |
| 03 | Text and image features | Convert words and images into numbers that ML models understand. |
| 04 | Linear regression | Predict a numeric value using relationships between inputs and outputs. |
| 05 | Classification | Predict a category, such as survival or non-survival. |
| 06 | Model training | Train and save a classifier for later reuse. |
| 07 | CNN layers | Use convolution and pooling to extract visual patterns. |
| 08 | Digit recognition | Classify handwritten digit images into 0–9. |

## How to use

1. Install Python and Jupyter Notebook (or open the notebooks in Google Colab).
2. Open one `labXX` folder at a time.
3. Run the notebook cells in order, checking any file paths or package requirements.
4. Use `VIVA_GUIDE.md` to prepare short explanations.

Some notebooks require extra libraries, internet access, or specific local file paths; they have **not** been verified end-to-end in a fresh environment. The original code is preserved rather than rewritten into potentially different results.

## Files

Each lab contains its primary notebook or training script and relevant input data. Unnecessary duplicate notebooks, deployment files, saved model binaries, and large collections of generated figures were excluded to keep this version easy to navigate.
